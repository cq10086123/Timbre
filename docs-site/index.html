为什么是 Timbre？

市面上的播放器大多是「音乐播放器顺便能放长音频」，Timbre 是反过来的。

☁️

NAS 变书架：WebDAV 远程书库

  • 一键整库入库：目录树随便逛，不用一集一集点
  • 封面全自动：cover.jpg 优先于内嵌图，手动选的永不覆盖
  • 实时上架：导入中封面就挂上书架，不用等一千集读完
  • 边下边听：播放缓存 + 章节预取 + 上限可调
  • 绝不莫名失败：密码失效红字提示重新输入
🎧

真正为「听书」设计

  • 跳过片头片尾：每本书每集独立设置
  • 断点续播：每一秒的位置都记得
  • 暂停自动回退、渐弱睡眠定时、倍速、音量增益、书签
  • Android Auto 与桌面小部件
📚

为千集大书库而生

  • 自然排序：第 2 集排在第 10 集前，「第二十章」也认得
  • 边导入边听：第一集解析完就能听
  • 正在听 / 未开始 / 已完成自动分组，全局搜索
  • M4B / MP3 / M4A / OGG / OPUS / FLAC / WAV 通吃
🎨

与系统浑然一体

  • 全量简体中文，覆盖每一个界面文案
  • Material You 动态取色
  • 深色 / 浅色 / 跟随系统

三步开始听

从 NAS 到耳朵，不折腾。

连上你的书库

本地文件夹一次导入，或添加 WebDAV 服务器，整库入库。

自动整理好

封面、排序、分组全自动，第 2 集永远排在第 10 集前面。

戴上耳机听

断点续播 + 跳过片头片尾 + 睡眠定时，打开就是上次的位置。
