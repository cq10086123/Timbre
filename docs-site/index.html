为什么是 Timbre？

市面上的播放器大多是「音乐播放器顺便能放长音频」，Timbre 是反过来的。

☁️

NAS 变书架：WebDAV 远程书库

  • 添加服务器（HTTP/HTTPS，Basic / Digest 认证），目录树随便逛，一键整库入库
  • 封面全自动：文件夹里的 cover.jpg 优先于内嵌图；手动选的封面永不覆盖
  • 导入进行中封面就实时挂上书架——不用等一千多集读完
  • 边下边听：播放缓存、章节预取、上限可调，WLAN 自动刷新
  • 密码失效会红字提示重新输入，绝不「莫名失败」
🎧

真正为「听书」设计

  • 跳过片头片尾：每本书每集独立设置，细节逻辑不打架
  • 断点续播：每一秒的位置都记得
  • 暂停自动回退、渐弱睡眠定时、倍速、音量增益、书签
  • Android Auto 与桌面小部件
📚

为千集大书库而生

  • 自然排序：第 2 集排在第 10 集前，「第二十章」也认得
  • 边导入边听：千集长书逐批入库，第一集解析完就能听
  • 正在听 / 未开始 / 已完成 自动分组，网格 / 列表、全局搜索
  • M4B / MP3 / M4A / OGG / OPUS / FLAC / WAV 通吃
🎨

与系统浑然一体

  • 全量简体中文，覆盖每一个界面文案
  • Material You 动态取色
  • 深色 / 浅色 / 跟随系统主题
🔒

零隐私顾虑

无账号、无广告、无统计、无追踪 SDK——一行都没有。书库、进度、书签、缓存全部留在你自己的设备上。唯一的联网行为：连你自己的 NAS，以及你主动搜索封面。详见 隐私政策。
