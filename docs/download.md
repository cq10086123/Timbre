# 下载安装

## 下载

1. 打开 [GitHub Releases 页面](https://github.com/cq10086123/Timbre/releases/latest)。
2. 在最新版本的 **Assets** 里下载 `timbre-v<版本号>.apk`。
3. 在手机上打开 APK 安装。如果系统提示「允许安装未知来源应用」，按提示授权一次即可。

[:material-download: &nbsp;前往最新版本](https://github.com/cq10086123/Timbre/releases/latest){ .md-button .md-button--primary }

## 系统要求

| 项目 | 要求 |
|---|---|
| Android 版本 | Android 9（API 28）及以上 |
| 安装包 | APK 直接安装，无需商店 |

## 覆盖安装与数据

新版本 APK 使用与旧版本相同的签名，可以**直接覆盖安装**，书库、播放进度、书签和设置全部保留，不需要卸载重装。

只有把书的**音频文件**从手机上删掉，数据才会随书一起消失。

## 应用内更新

从 v1.0.10 起，应用会在启动后自动在后台检查新版本（每天最多一次，不发送任何数据）：

- 检测到新版本时会弹窗提示，点击「**立即更新**」跳转到浏览器下载；
- 点击「**取消**」后，同一个版本不会再打扰你，直到有更新的版本发布；
- 检查失败（例如无网络）时静默忽略，不影响任何功能。

## 应用也可以检查到的新版本

设置最下方的「**软件版本**」行会显示当前版本；当有新版本时，这一行会变成「可更新到 x.y.z」，点击即可前往下载页。
