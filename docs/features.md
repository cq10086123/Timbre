# 功能特性

## 播放

- **断点续播**：每一本书、每一集的位置都会自动记住。
- **倍速播放**：0.5x ~ 2.0x 无级调节。
- **音量提升**：在系统音量之外额外放大音量。
- **跳过空白部分**：自动跳过音频中的静音段。
- **睡眠定时器**：定时停止播放，支持淡出，还可以设置在某个时间段开始播放时自动开启。

## 跳过片头片尾

在播放页右上角的 `⋮` 菜单里，**每本书可以单独设置**：

- **跳过片头**：每次进入一集时自动跳过开头 N 秒（0~120 秒，1 秒步进）。
- **跳过片尾**：播到本集结束前 N 秒时自动进入下一集。

一些刻意的细节：

- 片头**每集只跳一次**，不会和你暂停后的自动回退互相打架；
- **暂停状态不会触发片尾跳过**——暂停在片尾是你自己选的位置；
- **最后一集不跳片尾**，让它正常播完，避免"书还没听完就提前没了声音"。

## 自动封面

导入时，封面按下面的优先级自动确定：

1. **文件夹里的图片**：扫描书所在文件夹，找到图片就直接做封面；WebDAV 书同样适用（图片会从服务器下载后作为封面）。本地多张就随机挑一张，WebDAV 书则优先选 `cover` / `folder` / `poster` 这类常见封面名，其余按文件名排序，保证每次扫描结果一致。jpg / png / webp / heic 等常见格式都支持，解码失败的文件会自动跳过。
2. **音频内嵌封面**：读取前几集音频文件里内嵌的封面图。
3. **自动生成**：什么都没有时，按书名生成一张渐变封面。

之后往文件夹里补图，会自动替换生成的占位封面；WebDAV 书在下一次扫描（重新打开应用或重新导入时触发）也会换上文件夹里的新图；你手动指定的封面永远不会被自动覆盖。

## 应用内更新

启动后后台静默检查新版本（每天最多一次），发现更新时弹窗提示，可取消、可一键前往下载页。详见[下载安装](download.md)。

## 自动回退与跳过时间

在「偏好设置」里可以全局调整：

- **跳过时间**：播放键两侧快进/快退按钮一次跳多少秒（3~60 秒）。
- **自动回退**：按暂停时自动往回退几秒，恢复播放时重听最后几个字，不会漏掉内容。

## Android Auto 与蓝牙

支持 Android Auto 与蓝牙耳机的媒体控制。
